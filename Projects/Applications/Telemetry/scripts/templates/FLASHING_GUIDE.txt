Wio-E5 Telemetry Production Flash Guide
======================================

This package contains firmware built from production profile:
- firmware/telemetry.hex  (recommended for flashing)
- firmware/telemetry.bin
- firmware/telemetry.elf
- firmware/telemetry.map
- docs/build_manifest_full.json
- docs/build_manifest_redacted.json
- docs/build_manifest_summary.txt

Factory lifecycle (AT firmware -> Telemetry firmware)
----------------------------------------------------

1) Incoming board is expected to run default factory AT firmware.
2) Connect device over USB-C and confirm serial interface is visible.
3) Switch board into STM32 ROM bootloader mode.
4) Flash telemetry firmware with one of the methods below.
5) Reset board and verify application boot (not AT prompt).
6) Continue with LoRaWAN join commissioning using the manifest values.

LoRaWAN commissioning checklist (per device)
--------------------------------------------

- Device identity must be unique for each installed node:
  - DevEUI
  - JoinEUI
  - AppKey
  - NwkKey
- Confirm region and activation mode in build manifest.
- Before field deployment, verify that this build can join the target network.

Manifest usage during deployment
--------------------------------

- `build_manifest_full.json` is internal evidence for manufacturing/service.
- `build_manifest_redacted.json` is safe for broader sharing.
- `build_manifest_summary.txt` gives quick human-readable traceability.
- Always archive manifest together with installation record for the specific device.

Flashing options
----------------

1) ST-LINK/SWD (recommended)
   Linux/macOS:
   - Use flash/flash_stlink.sh
   - Example:
     ./flash/flash_stlink.sh ../firmware/telemetry.hex "$HOME/STMicroelectronics/STM32Cube/STM32CubeProgrammer/bin/STM32_Programmer_CLI"

2) UART bootloader
   Linux/macOS:
   - Put board into ROM boot mode (BOOT button/pin + RESET).
   - Use flash/flash_uart.sh
   - Example:
     ./flash/flash_uart.sh ../firmware/telemetry.hex /dev/ttyUSB0 115200 "$HOME/STMicroelectronics/STM32Cube/STM32CubeProgrammer/bin/STM32_Programmer_CLI"

   Windows:
   - Put board into ROM boot mode.
   - Use flash/flash_uart_windows.bat
   - Example:
     flash_uart_windows.bat ..\firmware\telemetry.hex COM5 115200 "C:\Program Files\STMicroelectronics\STM32Cube\STM32CubeProgrammer\bin\STM32_Programmer_CLI.exe"

Prerequisites
-------------
- STM32CubeProgrammer installed.
- For UART method: proper USB-UART drivers and known COM/TTY port.

Verification after flashing
---------------------------
- Device boots after reset.
- LoRaWAN join path starts.
- Heartbeat and alarm behavior follow expected application logic.
- Manifest values match intended deployment parameters.

Notes
-----
- This package is production build output, not emulation harness output.
- If flashing fails, verify wiring, boot mode, and CLI path.
